# JLPT N2 vocabulary questions: the real format

Source: the official N2 sample test, `https://www.jlpt.jp/samples/sample2012/pdf/N2V.pdf`
(pages 7–10) and `N2answer.pdf`. Re-check there if anything looks off.

## Counts and instructions (word for word)

| 大問 | Qs | Instruction | Sample answers |
|---|---|---|---|
| 問題3 語形成 | 5 | （　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。 | 1 2 1 4 2 |
| 問題4 文脈規定 | 7 | （　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。 | 4 4 1 2 1 1 2 |
| 問題5 言い換え類義 | 5 | ＿＿＿の言葉に意味が最も近いものを、1・2・3・4から一つ選びなさい。 | 3 4 1 3 3 |

(問題1–2 are the kanji questions; see the jlpt-kanji-quiz-terminal skill.)

## 問題3 語形成: one-kanji prefix or suffix

- 彼は医学（**界**）ではかなり知られた存在だ。 — 界 / 帯 / 域 / 区
- 決勝戦で負けて、（**準**）優勝に終わった。 — 後 / 準 / 次 / 副
- （**現**）段階では詳細は決まっていないらしい。 — 現 / 直 / 近 / 当
- 今回の大臣の訪問は（**非**）公式に行われた。 — 不 / 未 / 無 / **非**
- わが社の今年の（**総**）売上は、昨年を上回った。 — 集 / 総 / 合 / 満

Choices are 4 single kanji from the same family (all negatives 不未無非, all "area"
suffixes 界帯域区, all "next/vice" prefixes 後準次副). Only one attaches to that word.

## 問題4 文脈規定: the word that fits the sentence

- さまざまなデータを（**分析**）した結果、事故の原因が明らかになった。 — 視察 / 検査 / 発明 / 分析
- 街を（**ぶらぶら**）していたら、山本さんに会った。 — ぐらぐら / がらがら / ばらばら / ぶらぶら
- 祭りの日は町が（**活気**）にあふれている。 — 活気 / 活発 / 活躍 / 活動
- コピー機に紙が（**つまって**）、出てこない。 — もぐって / つまって / しずんで / うまって
- この小説は今の時代を（**反映**）した作品だ。 — 反映 / 放映 / 引用 / 採用
- 田中さんは長い間（**ぼんやり**）窓の外を見ていた。 — ぼんやり / ふんわり / うっすら / しっとり
- 経済だけでなく、法律にも詳しいのが彼の（**強み**）だ。 — 深み / 強み / 高み / 重み

Traps: words sharing a kanji (活気/活発/活躍/活動, 反映/放映), onomatopoeia of the same
shape (ぐらぐら/がらがら/ばらばら/ぶらぶら), verbs of the same form (〜って), nouns with the
same suffix (深み/強み/高み/重み). The meaning is close; the **collocation** decides
(活気にあふれる, 紙がつまる).

## 問題5 言い換え類義: closest meaning

- このブームは長くは続かないだろう。 → 効果 / 状態 / **流行** / 緊張
- この作業は慎重にやってください。 → 急いで / 絶対忘れずに / 静かに / **十分注意して**
- シャツがちぢんでしまった。 → **小さくなって** / 古くなって / 汚れて / 破れて
- 宿題のレポートはほぼ終わった。 → すべて / すぐに / **だいたい** / やっと
- 来週は天気が回復するそうだ。 → あまり変わらない / 変わりやすい / **よくなる** / 悪くなる

The target is often katakana, an adverb or a 漢語; the answer is a plain paraphrase.
Wrong choices fit the sentence grammatically, so only the meaning decides.

## 問題6 用法: the one correct use

The word is given alone, then 4 sentences using it:

- **方針**: 台風の方針がそれた ✗ (進路) / 今年の方針は漢字を600字 ✗ (目標) / 料理を作る方針 ✗ (方法) / **政府の方針が大きく変わった** ✓
- **範囲**: 町は二つの範囲に分かれ ✗ (地域) / 新しい範囲に進出 ✗ (分野) / **広い範囲で強い雨** ✓ / 駅までの範囲は2キロ ✗ (距離)
- **せめて**: せめて1万円はする ✗ (少なくとも) / せめて10時には着けない ✗ (とても) / **せめて1泊はしたい** ✓ / せめて50点は取れた ✗ (少なくとも)
- **利益**: 健康の利益 ✗ (ため) / **店の利益はほとんどない** ✓ / 利益が感じられない ✗ (効果) / バスの利益は ✗ (利点)
- **かなう**: 苦労がかない ✗ (実り) / 天気予報がかない ✗ (当たり) / イベントが無事かなった ✗ (終わった) / **夢がかなった** ✓

Each wrong sentence uses the word where a **near-synonym** belongs (in parentheses).
All 4 sentences are grammatical; only the right collocation or nuance makes one correct.

## What this means when writing questions

- 語形成: 4 single kanji from one family; only one makes a real word with the stem.
- 文脈規定: same-shape choices (shared kanji, same suffix, same ending, same onomatopoeia
  pattern); the context or collocation decides.
- 言い換え: a plain paraphrase as the answer; distractors that also fit the sentence.
- 用法: 4 natural sentences; 3 put the word where a near-synonym belongs. Know which
  near-synonym each wrong one wants, for the explanation.
- Spread answers over 1–4 with no pattern.
