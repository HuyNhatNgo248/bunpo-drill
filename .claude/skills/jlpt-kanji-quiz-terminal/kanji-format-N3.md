# JLPT N3 kanji questions: the real format

Source: the official N3 sample test, `https://www.jlpt.jp/samples/sample2012/pdf/N3V.pdf`
(pages 5–6). The answer PDF is not linked from the site; the answers below are solved,
and none is in doubt.

## Counts

| 大問 | Questions | Answers in the sample |
|---|---|---|
| 問題1 漢字読み | 8 | 3 2 2 3 1 4 2 4 |
| 問題2 表記 | 6 | 3 4 1 2 2 3 |

Every question has 4 choices, numbered 1–4. One short everyday sentence per question, with
the target word underlined. Kanji above N3 outside the target get furigana (太陽, 奨学金, 成績,
山口, 東京); in the app, just avoid them outside the target.

## Instructions, word for word

- 問題1: ＿＿＿のことばの読み方として最もよいものを、1・2・3・4から一つえらびなさい。
- 問題2: ＿＿＿のことばを漢字で書くとき、最もよいものを、1・2・3・4から一つえらびなさい。

(N3 writes ことば and えらびなさい in hiragana; N2 writes 言葉 and 選びなさい.)

## 漢字読み: the 8 sample questions and their traps

| Sentence (target) | Choices | Trap type |
|---|---|---|
| 日本の<u>首都</u>はどこですか。 | しゅとう / しゅうと / **しゅと** / しゅうとう | long vowel × long vowel, a 2×2 grid |
| 地球は太陽のまわりを回っている。 (<u>地球</u>) | じきゅう / **ちきゅう** / じきゅ / ちきゅ | voicing × long vowel, a 2×2 grid |
| あの時計は<u>遅れて</u>いる。 | こわれて / **おくれて** / たおれて / よごれて | kun verbs with the same 〜れて ending |
| 二人で<u>協力</u>すれば、仕事も早く終わるだろう。 | きょりょく / どりょく / **きょうりょく** / どうりょく | long vowel × a look-alike word (努力), a 2×2 grid |
| 大学の奨学金に<u>応募</u>した。 | **おうぼ** / おうも / おうぼう / おうもう | ボ/モ × long vowel, a 2×2 grid |
| 子どもの<u>疑問</u>に答えた。 | くもん / きもん / ぐもん / **ぎもん** | voicing × き/く, a 2×2 grid |
| 試験の成績が<u>発表</u>された。 | はつひょう / **はっぴょう** / はつひょ / はっぴょ | っ+半濁音 × long vowel, a 2×2 grid |
| 単語のリストはとなりのページにあります。 (<u>単語</u>) | げいご / けいご / だんご / **たんご** | voicing × a different first syllable; all real-sounding words |

So the wrong readings are:
- **2×2 grids**, nearly every question: long vowel, voicing (か/が, た/だ, ひ/ぴ), っ, and
  similar sounds (ぼ/も, き/く) crossed. Exactly one cell is right.
- **Kun verbs with the same okurigana**: all 〜れて.
- Traps are simpler than N2: the sound changes, not rare on readings.

## 表記: the 6 sample questions and their traps

| Sentence (target in hiragana) | Choices | Trap type |
|---|---|---|
| みんなで話し合って、問題を<u>かいけつ</u>した。 | 改決 / 改結 / **解決** / 解結 | 2×2 grid: 解/改 same sound カイ, 決/結 same sound ケツ |
| 山口さんに東京を<u>あんない</u>してもらった。 | 安内 / 家内 / 室内 / **案内** | first kanji swapped: same sound (安), real words (家内, 室内) |
| わたしは<u>けんこう</u>のために毎日走っています。 | **健康** / 建康 / 健庫 / 建庫 | 2×2 grid: 健/建 same sound and shape, 康/庫 same shape |
| 今年の夏は<u>きおん</u>が高かった。 | 気湿 / **気温** / 気湯 / 気混 | second kanji swapped for same-radical (氵) kanji |
| 頭が<u>いたい</u>ので、薬を飲んだ。 | 病い / **痛い** / 疲い / 症い | same radical (疒), same okurigana |
| このシャツは工場で<u>たいりょう</u>に作られている。 | 多量 / 多料 / **大量** / 大料 | 2×2 grid: 大/多 related meaning, 量/料 same sound リョウ |

So the wrong spellings are:
- **2×2 grids**: each kanji swapped for a same-sound or same-shape one.
- **Same radical**: 氵 for 温, 疒 for 痛, with the same okurigana for adjectives and verbs.
- **Real words as traps**: 家内, 室内, 多量.

## What this means when writing questions

- One short, everyday sentence at N3 level, target word underlined (in the app: 【 】).
- Build distractors with the patterns above: mostly 2×2 sound grids for 漢字読み, 2×2
  same-sound / same-shape grids and same-radical swaps for 表記.
- Wrong choices must be clearly wrong to someone who knows the word.
- Spread answers over 1–4 with no pattern.
